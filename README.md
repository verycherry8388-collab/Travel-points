# TravelPoints MVP

A demo prototype for a proprietary travel-rewards currency (TPX).

## Included
- Home dashboard
- Free TPX rewards
- Buy TPX demo flow
- Wallet + immutable-style transaction ledger
- Demo hotel search
- Liquidation deals
- TPX + cash checkout
- Booking confirmation
- Simple admin dashboard

## Run
This is a static prototype. Open `index.html` in a browser.

No real payments or hotel bookings are connected. Replace demo inventory/payment logic with authorized production providers before launch.
